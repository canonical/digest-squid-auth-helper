# digest-squid-auth-helper Terraform module

This folder contains a base [Terraform][Terraform] module for the digest-squid-auth-helper
charm.

The module uses the [Terraform Juju provider][Terraform Juju provider] to model the charm
deployment onto any machine environment managed by [Juju][Juju].

digest-squid-auth-helper is a subordinate charm: it does not declare `units` and must be
integrated with a principal charm (such as [squid-reverseproxy][squid-reverseproxy]) through
its `squid-auth-helper` relation.

## Module structure

- **main.tf** - Defines the Juju application to be deployed.
- **variables.tf** - Allows customization of the deployment. Also models the charm configuration,
  except for exposing the deployment options (Juju model UUID, channel or application name).
- **outputs.tf** - Integrates the module with other Terraform modules, primarily
  by defining potential integration endpoints (charm integrations), but also by exposing
  the deployed Juju application.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using digest-squid-auth-helper base module in higher level modules

If you want to use `digest-squid-auth-helper` base module as part of your Terraform module,
import it like shown below. Always pin the `?ref=` to a released tag or a commit hash: CC008
does not allow floating references such as branches.

```text
data "juju_model" "my_model" {
  name = var.model
}

module "digest-squid-auth-helper" {
  source = "git::https://github.com/canonical/digest-squid-auth-helper//terraform?ref=tf-1.0.0"

  model_uuid = data.juju_model.my_model.uuid
  # (Customize configuration variables here if needed)
}
```

Create integrations, for instance:

```text
resource "juju_integration" "digest-squid-auth-helper-squid" {
  model_uuid = data.juju_model.my_model.uuid
  application {
    name     = module.digest-squid-auth-helper.application.name
    endpoint = module.digest-squid-auth-helper.requires.squid-auth-helper.endpoint
  }
  application {
    name     = "squid-reverseproxy"
    endpoint = "squid-auth-helper"
  }
}
```

The complete list of available integrations can be found [in the Integrations tab][digest-squid-auth-helper-integrations].
